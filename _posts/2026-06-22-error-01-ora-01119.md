TBS 생성 중 오류 발생.

```sql
SQL> CREATE TABLESPACE tblspace1
  2  DATAFILE '/oracle2/oradata/GD2/tblspace1_01.dbf'
  3  SIZE 100M
AUTOEXTEND ON
NEXT 100M
MAXSIZE 5G
EXTENT MANAGEMENT LOCAL
SEGMENT SPACE MANAGEMENT AUTO;    4    5    6    7    8
CREATE TABLESPACE tblspace1
*
ERROR at line 1:
ORA-01119: error in creating database file
'/oracle2/oradata/GD2/tblspace1_01.dbf'
ORA-27040: file create error, unable to create file
Linux-x86_64 Error: 2: No such file or directory
Additional information: 1
```

## 해결
데이터파일 지정 경로가 없어서 생긴 오류. 실제 경로를 만들어주거나 쿼리에서 경로를 변경하면 된다.

```sql
SQL> CREATE TABLESPACE tblspace1
  2  DATAFILE '/oracle2/base/oradata/GD2/tblspace1_01.dbf'
  3  SIZE 100M
  4  AUTOEXTEND ON
NEXT 100M
  5    6  MAXSIZE 5G
EXTENT MANAGEMENT LOCAL
SEGMENT SPACE MANAGEMENT AUTO;       7    8

Tablespace created.
```
