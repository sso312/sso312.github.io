```bash
[oracle@psh OPatch]$ $ORACLE_HOME/OPatch/opatch rollback -id 39034528

   from           : /oracle2/base/19c/oraInst.loc

Prerequisite check "CheckActiveFilesAndExecutables" failed.

Patch 39034528:

Following active files/executables/libs are used by ORACLE_HOME :/oracle2/base/19c
/oracle2/base/19c/lib/libclntsh.so.19.1
/oracle2/base/19c/lib/libsqlplus.so

Log file location: /oracle2/base/19c/cfgtoollogs/opatch/opatch2026-06-16_04-21-41AM_1.log

OPatch failed with error code 73
```

## 원인
OPatch 중에 Oracle Home 안의 파일을 어떤 프로세스가 사용 중이라서 패치 적용이 막힌 상황.

## 해결
실행 중인 프로세스를 찾아 중지하거나, db·listener를 다 닫았으면 터미널까지 닫고 새로 연다.

```bash
[oracle@psh OPatch]$ ps -ef | grep pmon
oracle   28272 26962  0 04:31 pts/1    00:00:00 grep --color=auto pmon
[oracle@psh OPatch]$ lsof | grep /oracle2/base/19c
sqlplus   25613              oracle  txt       REG  253,0     24800  76255539 /oracle2/base/19c/bin/sqlplus
```
