## 상황
runInstaller로 설치하다가 멈춰서 다시 실행.

| 항목 | 의미 |
|---|---|
| /home/oracle/u01/app/product/19c | 이미 Oracle Home으로 등록됨 |
| 중앙 인벤토리 | 이 Oracle Home 정보를 이미 가지고 있음 |
| runInstaller 재실행 | "새로운 DB Home 설치"로 인식 |
| 결과 | 이미 등록된 홈이라 설치 불가 |

## 원인 및 해결
ORACLE_HOME 디렉터리를 삭제하고 새로운 경로로 재생성한 뒤, 압축을 풀고 runInstaller를 다시 실행한다.
