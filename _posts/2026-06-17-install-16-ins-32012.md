## 상황
Oracle 19c `applyRU` 진행 중 발생.

## 원인
해당 폴더에 권한을 안 줘서 생긴 문제.

## 해결
```bash
[root@psh ~]# chmod -R 755 /u01
[root@psh ~]# chown -R oracle:dba /u01
```
